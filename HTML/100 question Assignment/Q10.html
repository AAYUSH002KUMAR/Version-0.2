Viewport Meta Tag

The viewport meta tag helps a webpage display properly on different screen sizes such as mobile phones, tablets, and desktops.

Viewport Meta Tag Syntax

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Meaning

  • width=device-width : Sets the width of the webpage equal to the device's screen width.
  • initial-scale=1.0 : Sets the initial zoom level of the webpage to 100%.
